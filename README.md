A collection of PyCUDA examples, exercises, and practice codes for learning GPU programming with Python.

## 📋 Prerequisites

- **NVIDIA GPU** with CUDA Compute Capability 3.0+
- **CUDA Toolkit** (11.0 or higher)
- **Python** 3.7 or higher
- **PyCUDA** library

## 🚀 Installation

### 1. Install CUDA Toolkit
Download and install from [NVIDIA Developer Website](https://developer.nvidia.com/cuda-downloads)

### 2. Install PyCUDA
```bash
pip install pycuda
